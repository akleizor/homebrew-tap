# Akleizor Tap

## How do I install these formulae?

`brew install akleizor/tap/<formula>`

Or `brew tap akleizor/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "akleizor/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
